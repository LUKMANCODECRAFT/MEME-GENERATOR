# ⚡ MemeStudio PRO - Next-Generation Interactive Meme Creator

**MemeStudio PRO** is a modern, high-performance, studio-grade web application designed for creating, styling, and exporting viral memes with precision and speed.

---

## ✨ Features & Highlights

### 🎨 1. Studio-Grade Canvas Engine
- **Direct Interactive Manipulation**: Click and drag any text, sticker, or shape layer directly across the canvas.
- **Transform Handles**: 4-corner scaling, bounding box guidelines, and top rotation lever (with `Shift` key snapping).
- **Multi-Touch & Pointer Support**: Full responsive interaction on desktops, laptops, tablets, and mobile devices.
- **High-DPI Retina Rendering**: Automatic scale-up for crystal-clear text and graphic output.

### 🖼️ 2. Curated Meme Templates & Image Studio
- **12+ Built-in Popular Meme Formats**:
  - *Drake Hotline Bling*
  - *Distracted Boyfriend*
  - *Two Buttons Dilemma*
  - *Buff Doge vs. Cheems*
  - *Woman Yelling at Cat*
  - *Roll Safe (Thinking Guy)*
  - *Spider-Man Pointing*
  - *Change My Mind (Desk)*
  - *Disaster Girl*
  - *Trade Offer*
  - *Bernie Sanders "Once Again Asking"*
  - *Panik Kalm Panik*
- **Custom Image Upload**: Drag & drop any image file onto the canvas or dropzone.
- **Clipboard Paste (`Ctrl+V`)**: Press `Ctrl+V` anywhere on the page to instantly paste screenshots or copied images.
- **Aspect Ratio Switcher**: Switch between **1:1 Square (Instagram)**, **9:16 Story/Reels/TikTok**, **16:9 Landscape**, and **4:5 Portrait**.

### ✍️ 3. Typography & Text Styling
- **Custom Font Families**: *Impact, Anton, Montserrat, Bebas Neue, Permanent Marker, Inter Bold*.
- **Classic Outline / Stroke**: Custom stroke width slider and stroke color picker.
- **Format Controls**: Font size slider, Text alignment (Left, Center, Right), ALL-CAPS toggle, and Drop Shadows.
- **Banner Pill / Breaking News Boxes**: Optional colored background banner behind text for news or breaking meme formats.

### 🎭 4. Stickers, Emojis & Meme Props
- **Categorized Sticker Deck**: *Meme Essentials*, *Faces*, *Reactions*, *Props & Hats*, *Badges & Arrows*.
- **Custom Sticker Image Upload**: Upload PNG logos, transparent cutouts, or faces to place over memes.
- **Meme Shapes & Markers**: Red arrows, focus circles, speech bubbles, and thug life sunglasses.

### 🪄 5. Photo Filters & Transformations
- **One-Click Presets**: *Deep Fried 🔥*, *Vintage 📻*, *Cyberpunk 👾*, *Noir B&W 🖤*, *Warm Glow ☀️*.
- **Precision Sliders**: Real-time Brightness, Contrast, Saturation, Sepia, Blur, and Invert.
- **Transforms**: Flip Horizontal (`↔`), Flip Vertical (`↕`), and Rotate 90° (`↻`).

### ⏪ 6. History & Layer Management
- **Full Undo / Redo**: Unlimited history tracking with keyboard shortcuts (`Ctrl+Z`, `Ctrl+Y`).
- **Layer Panel**: View active layers, toggle layer visibility (`👁️`), delete, duplicate (`Ctrl+D`), and reorder.

### 🚀 7. Pro Export Tools
- **High-Resolution Export**: Export in 1x Standard, 2x HD, or 4x Ultra resolution.
- **Multiple Formats**: Lossless **PNG**, Compressed **JPEG**, and Modern **WebP**.
- **1-Click Copy to Clipboard**: Copies the rendered image directly into your clipboard for immediate pasting into Discord, Slack, Twitter/X, or WhatsApp.

---

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Ctrl + Z` | Undo last action |
| `Ctrl + Y` / `Ctrl + Shift + Z` | Redo action |
| `Ctrl + C` | Copy meme image to clipboard |
| `Ctrl + D` | Duplicate selected layer |
| `Delete` / `Backspace` | Delete active layer |
| `Ctrl + V` | Paste image from clipboard |
| `Shift + Drag (Rotate)` | Snap rotation to 15° increments |

---

## 💻 Tech Stack
- **Structure**: Semantic HTML5 with accessible UI architecture.
- **Styling**: Vanilla CSS3 design system with CSS custom properties, Dark Glassmorphism, and responsive CSS Grid / Flexbox.
- **Engine**: Object-Oriented JavaScript Canvas Engine (Zero heavy third-party framework dependencies, lightning fast load time).

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve via any static HTTP server:
```bash
# Using python
python -m http.server 3000

# Using Node / npx serve
npx serve .
```
